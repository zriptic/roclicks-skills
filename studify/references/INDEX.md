# Reference gallery index: 142-image dataset (July 2026)

The reference images are not bundled with this skill. They are other creators'
builds, so they are shown in the online gallery instead:
https://roclicks.gg/assets#stud-references

Read `style-notes.md` first, then open the 3-6 gallery images whose group
matches the job (save them to a scratch folder if your tools need local files
to view them). Several images often show the same build from different
angles. The dataset covers these groups:
